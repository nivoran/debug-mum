Structures de Données et Algorithmes en Python

1. Structures linéaires : Introduction

Une structure de données linéaire organise les données de manière séquentielle. En Python, le type primitif list sert de base pour la plupart de ces structures linéaires grâce à sa gestion dynamique de la mémoire.

Caractéristiques principales en Python :

  • Dynamicité native : Les tableaux dynamiques de Python (list) redimensionnent leur capacité automatiquement.
  • Indexation directe : Accès direct aux éléments par leur indice en $O(1)$ (ex. tableau[i]).
  • Gestion simplifiée : L'allocation et la libération mémoire sont prises en charge par le ramasse-miettes (Garbage Collector).

Vue d'ensemble des structures étudiées :

  1. Les Listes : Manipulation dynamique avec insertion et suppression flexibles.
  2. Les Piles (LIFO) : Implémentées nativement avec les méthodes append() et pop().
  3. Les Files (FIFO) : Optimisées grâce au module collections.deque.

1.1 Liste : Définition

En Python, une liste est un tableau dynamique ordonné et modifiable pouvant contenir des éléments de types hétérogènes.

Composition et Propriétés :

  • Indexation de 0 à N-1 : Accès en $O(1)$ via l'indice.
  • Taille variable : La fonction len(ma_liste) renvoie le nombre d'éléments présents.
  • Coût des opérations : Ajouter ou supprimer au milieu d'une liste nécessite un décalage interne des éléments ($O(N)$).

1.1.1 Créer une liste

La création d'une liste vide s'effectue simplement avec des crochets [] ou via le constructeur list().

Algorithme général :

Algorithme InitialiserListe() Sortie : Une liste vide Début ma_liste <- [] Retourner ma_liste Fin

1.1.2 Ajouter un élément à une liste

Python fournit des méthodes intégrées pour insérer des éléments :

  • append(element) : Ajoute à la fin de la liste ($O(1)$ amorti).
  • insert(index, element) : Insère un élément à un indice donné en décalant les éléments suivants ($O(N)$).

Algorithme :

Algorithme Inserer(liste, element, pos) Entrée / Sortie : liste Entrée : element, pos (Entier) Début Insérer element à l'indice pos dans liste Fin

1.1.3 Supprimer un élément d’une liste

Plusieurs approches existent pour la suppression :

  • pop(index) : Supprime et retourne l'élément situé à l'indice donné.
  • remove(valeur) : Supprime la première occurrence d'une valeur.
  • del liste[index] : Supprime l'élément à l'indice spécifié.

Algorithme :

Algorithme Supprimer(liste, pos) Entrée / Sortie : liste Entrée : pos (Entier) Début Supprimer l'élément situé à l'indice pos dans liste Fin

1.1.4 Concaténer deux listes

La concaténation s'effectue via l'opérateur + ou la méthode extend().

Algorithme :

Algorithme Concatener(liste1, liste2) Entrée : liste1, liste2 Sortie : Une nouvelle liste contenant les éléments des deux listes Début Retourner liste1 + liste2 Fin

1.1.5 Implémentation en Python

Exemple de manipulations de listes en Python :

# Initialisation L1 = [] L2 = [40, 50] # Ajout d'éléments L1.append(10) # [10] L1.append(30) # [10, 30] L1.insert(1, 20) # [10, 20, 30] print("L1 :", L1) # Suppression element_supprime = L1.pop(0) # Supprime 10 -> L1 devient [20, 30] print("Après suppression du premier élément :", L1) # Concaténation L1.extend(L2) # [20, 30, 40, 50] print("Après concaténation :", L1)

1.2 Pile : Définition

Une pile (Stack) est une structure linéaire régie par le principe LIFO (Last In, First Out). En Python, une simple liste répond parfaitement à ce besoin en utilisant append() et pop().

1.2.1 Empiler

Ajouter un élément au sommet de la pile s'effectue via la méthode append() en $O(1)$.

Algorithme :

Algorithme Empiler(pile, element) Début pile.append(element) Fin

1.2.2 Dépiler

Retirer l'élément du sommet de la pile s'effectue via pop() (sans argument) en $O(1)$.

Algorithme :

Algorithme Depiler(pile) Début Si pile n'est pas vide Alors Retourner pile.pop() Sinon Afficher "Erreur : Pile vide" FinSi Fin

1.2.3 Vider

Réinitialiser la pile se fait en appelant la méthode clear().

Algorithme Vider(pile) Début pile.clear() Fin

1.2.4 Top

Lire l'élément au sommet sans le retirer s'effectue avec l'indexation négative pile[-1].

Algorithme ObtenirSommet(pile) Début Si pile n'est pas vide Alors Retourner pile[-1] FinSi Fin

1.2.5 Implémentation en Python

class Pile: def __init__(self): self._items = [] def est_vide(self): return len(self._items) == 0 def empiler(self, element): self._items.append(element) def depiler(self): if not self.est_vide(): return self._items.pop() raise IndexError("Dépiler depuis une pile vide") def top(self): if not self.est_vide(): return self._items[-1] raise IndexError("Consultation d'une pile vide") def vider(self): self._items.clear() # Exemple d'utilisation p = Pile() p.empiler(5) p.empiler(15) p.empiler(25) print("Sommet :", p.top()) # 25 print("Dépilé :", p.depiler()) # 25

1.3 File : Définition

Une file (Queue) suit le principe FIFO (First In, First Out : Premier entré, premier sorti). Bien qu'une liste Python puisse servir de file, l'opération pop(0) a un coût en $O(N)$. Pour garantir des opérations d'enfilage et de défilage en $O(1)$, on privilégie la structure de liste doublement chaînée fournie par le module standard collections.deque.

1.3.1 Défiler

L'opération Défiler consiste à retirer et retourner l'élément le plus ancien situé en tête de la file.

Algorithme :

Algorithme Defiler(file) Entrée / Sortie : file Sortie : valSortie Début Si Taille(file) > 0 Alors valSortie <- Retirer l'élément en tête de file (ex: file.popleft()) Retourner valSortie Sinon Afficher "Erreur : File vide" FinSi Fin

1.3.2 Enfiler

L'opération Enfiler ajoute un nouvel élément à la fin (la queue) de la file.

Algorithme :

Algorithme Enfiler(file, element) Entrée / Sortie : file Entrée : element Début Ajouter element à la fin de file (ex: file.append(element)) Fin

1.3.3 Vider

Réinitialiser la file se fait en supprimant la totalité de ses éléments.

Algorithme :

Algorithme Vider(file) Entrée / Sortie : file Début Supprimer tous les éléments de file (ex: file.clear()) Fin

1.3.4 Tail/Queue

L'opération Tail (ou consultation de la queue) permet d'accéder au dernier élément inséré sans le supprimer.

Algorithme :

Algorithme ObtenirTail(file) Entrée : file Sortie : valSortie Début Si Taille(file) > 0 Alors valSortie <- Dernier élément de file (ex: file[-1]) Retourner valSortie Sinon Afficher "Erreur : File vide" FinSi Fin

1.3.5 Implémentation en Python

from collections import deque class File: def __init__(self): self._elements = deque() def est_vide(self): return len(self._elements) == 0 def enfiler(self, element): self._elements.append(element) def defiler(self): if not self.est_vide(): return self._elements.popleft() raise IndexError("Défiler depuis une file vide") def tail(self): if not self.est_vide(): return self._elements[-1] raise IndexError("File vide") def vider(self): self._elements.clear() # Exemple d'utilisation f = File() f.enfiler(10) f.enfiler(20) f.enfiler(30) print("Défilé :", f.defiler()) # 10 print("Dernier élément (Tail) :", f.tail()) # 30

2. Algorithmes de recherche et de tri

Ce chapitre traite des algorithmes fondamentaux de recherche et de tri appliqués aux listes Python.

2.1 Recherche séquentielle

Définition

Parcours élément par élément du début à la fin. Complexité $O(N)$.

Pseudocode

Algorithme RechercheSequentielle(liste, valeur) Début Pour i de 0 à Taille(liste) - 1 Faire Si liste[i] == valeur Alors Retourner i FinSi FinPour Retourner -1 Fin

Implémentation en Python

def recherche_sequentielle(liste, valeur): for i, elem in enumerate(liste): if elem == valeur: return i return -1 T = [12, 4, 8, 25, 1] print("Indice :", recherche_sequentielle(T, 25)) # 3

2.2 Recherche dichotomique

Définition

Recherche par division successive du domaine de recherche. Nécessite une liste **triée**. Complexité $O(\log_2 N)$.

Pseudocode

Algorithme RechercheDichotomique(liste, valeur) Début debut <- 0 fin <- Taille(liste) - 1 Tant que debut <= fin Faire milieu <- (debut + fin) // 2 Si liste[milieu] == valeur Alors Retourner milieu Sinon Si liste[milieu] < valeur Alors debut <- milieu + 1 Sinon fin <- milieu - 1 FinSi FinTantQue Retourner -1 Fin

Implémentation en Python

def recherche_dichotomique(liste, valeur): debut, fin = 0, len(liste) - 1 while debut <= fin: milieu = (debut + fin) // 2 if liste[milieu] == valeur: return milieu elif liste[milieu] < valeur: debut = milieu + 1 else: fin = milieu - 1 return -1 T = [2, 5, 8, 12, 16, 23, 38] print("Indice :", recherche_dichotomique(T, 23)) # 5

2.3 Tri sélection

Définition

Recherche le plus petit élément du reste non trié et l'échange avec l'élément courant. Complexité $O(N^2)$.

Pseudocode

Algorithme TriSelection(liste) Début n <- Taille(liste) Pour i de 0 à n - 2 Faire min_idx <- i Pour j de i + 1 à n - 1 Faire Si liste[j] < liste[min_idx] Alors min_idx <- j FinSi FinPour Échanger liste[i] et liste[min_idx] FinPour Fin

Implémentation en Python

def tri_selection(liste): n = len(liste) for i in range(n - 1): min_idx = i for j in range(i + 1, n): if liste[j] < liste[min_idx]: min_idx = j liste[i], liste[min_idx] = liste[min_idx], liste[i] T = [64, 25, 12, 22, 11] tri_selection(T) print("Trié :", T)

2.4 Tri rapide

Définition

Tri récursif basé sur le choix d'un pivot. Complexité moyenne $O(N \log_2 N)$. En Python, ce tri peut être écrit très élégamment avec les compréhensions de listes.

Pseudocode

Algorithme TriRapide(liste) Début Si Taille(liste) <= 1 Alors Retourner liste pivot <- Premier élément Moindres <- Éléments < pivot Egaux <- Éléments == pivot Grands <- Éléments > pivot Retourner TriRapide(Moindres) + Egaux + TriRapide(Grands) Fin

Implémentation en Python

def tri_rapide(liste): if len(liste) <= 1: return liste pivot = liste[len(liste) // 2] moindres = [x for x in liste if x < pivot] egaux = [x for x in liste if x == pivot] grands = [x for x in liste if x > pivot] return tri_rapide(moindres) + egaux + tri_rapide(grands) T = [10, 7, 8, 9, 1, 5] print("Trié :", tri_rapide(T))

3. Langage Python

Python est un langage de programmation interprété, haut niveau, multi-paradigme et à typage dynamique, créé par Guido van Rossum et publié en 1991. Conçu avec une philosophie axée sur la lisibilité du code et la simplicité syntaxique, il résume sa vision dans le célèbre Manifeste The Zen of Python : « Simple is better than complex ».

1. Philosophie et Principes de Conception

Contrairement à d'autres langages imposant une lourdeur syntaxique, Python cherche à rendre le code compréhensible comme de l'anglais structuré :

  • Lisibilité avant tout : L'indentation (les espaces en début de ligne) est obligatoire et remplace les accolades {} ou les mots-clés begin/end. Cela élimine les débats de style et garantit une structure visuelle uniforme.
  • Expressivité : Une tâche nécessitant des dizaines de lignes en C ou en Java s'écrit souvent en quelques lignes en Python grâce aux constructions de haut niveau (comme les compréhensions de listes, le slicing ou les générateurs).
  • "Batteries Included" : Python est livré avec une bibliothèque standard d'une richesse exceptionnelle, offrant des modules natifs pour la manipulation de structures complexes (collections, heapq), les calculs mathématiques, le traitement de fichiers, et le réseau sans installer d'outils tiers.

2. Fonctionnement de l'Interpréteur et Exécution

Comprendre comment Python exécute un programme est essentiel pour analyser la performance des algorithmes :

  • Compilation en Bytecode : Lorsque vous lancez un script (.py), l'interpréteur (généralement CPython, écrit en C) le compile d'abord en un code intermédiaire appelé bytecode (fichiers .pyc dans le dossier __pycache__).
  • Machine Virtuelle Python (PVM) : La PVM lit ensuite ce bytecode instruction par instruction pour le traduire en commandes compréhensibles par le processeur. Ce fonctionnement par interprétation offre une excellente portabilité (le même code tourne sur Windows, macOS, Linux) au prix d'une vitesse d'exécution inférieure à un langage purement compilé comme C ou Rust.

3. Typage Dynamique et Gestion Automatique de la Mémoire

En Python, tout est objet (les entiers, les chaînes, les fonctions, et même les classes) :

  • Typage Dynamique Fort : Les variables ne sont pas des conteneurs typés, mais des étiquettes (références) pointant vers des objets en mémoire. Il n'y a pas besoin de déclarer int x. Cependant, le typage reste fort : Python n'autorise pas l'addition implicite d'une chaîne et d'un entier sans conversion explicite.
  • Gestion de la Mémoire & Ramasse-miettes (Garbage Collector) : Python gère automatiquement la réservation et la libération des espaces mémoire :
    • Comptage de Références : Chaque objet garde en mémoire le nombre de variables qui pointent vers lui. Dès que ce compteur tombe à zéro, l'espace mémoire est libéré immédiatement.
    • Garbage Collector (GC) : Un mécanisme complémentaire détecte et détruit les références cycliques (deux objets qui se pointent l'un l'autre sans être accessibles par le reste du programme).

4. Rôle de Python en Algorithmique et Data Science

Dans ce cours, Python est utilisé comme un formidable outil d'apprentissage algorithmique :

  • Prototypage Rapide : Il permet de se concentrer sur la logique, la complexité spatio-temporelle et la structure des données sans se faire piéger par des erreurs d'allocation mémoire (segmentation faults) ou de fuites mémoires (memory leaks).
  • Polyvalence Professionnelle : Maîtriser les structures de données en Python prépare directement aux domaines de l'Intelligence Artificielle, du Traitement Automatique du Langage Naturel (TALN), de la Data Science (NumPy, Pandas, PyTorch) et du Développement Web (Django, FastAPI).

3.1 Installation et Environnement de Développement

1. Téléchargement et Installation de Python

Pour pouvoir exécuter des scripts Python sur votre ordinateur :

  • Téléchargement : Rendez-vous sur le site officiel python.org/downloads et téléchargez la dernière version stable de Python 3.
  • Point critique lors de l'installation (Windows) : Veillez impérativement à cocher la case Add python.exe to PATH sur le premier écran de l'installeur avant de cliquer sur Install Now. Cela vous permettra de lancer Python directement depuis n'importe quel terminal.
  • Vérification : Ouvrez une invite de commandes (ou terminal) et tapez :
    python --version

2. Choix de l'Éditeur de Code (IDE)

Plusieurs outils permettent d'écrire et d'exécuter du code Python :

  • Visual Studio Code (VS Code) — Recommandé : Éditeur gratuit, léger et extrêmement complet.
  • PyCharm : Environnement de développement (IDE) dédié à Python développé par JetBrains (version Community gratuite).
  • IDLE : L'environnement basique directement fourni lors de l'installation de Python, pratique pour démarrer sans configuration.

3. Configuration de Visual Studio Code pour Python

Si vous optez pour VS Code, voici les étapes pour une configuration optimale :

  1. Télécharger VS Code : Depuis code.visualstudio.com.
  2. Installer l'extension Python :
    • Ouvrez VS Code et cliquez sur l'icône Extensions dans la barre latérale gauche (ou utilisez le raccourci Ctrl+Shift+X).
    • Dans la barre de recherche, tapez Python.
    • Sélectionnez l'extension officielle éditée par Microsoft et cliquez sur Install.
  3. Sélectionner l'interpréteur : Ouvrez la palette de commandes (Ctrl+Shift+P), tapez Python: Select Interpreter et choisissez la version de Python que vous avez installée.
  4. Exécuter un fichier : Créez un fichier avec l'extension .py (ex: main.py), écrivez votre code, puis cliquez sur le bouton Run / Play (▶) en haut à droite pour l'exécuter dans le terminal intégré.
