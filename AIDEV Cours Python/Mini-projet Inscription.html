Mini-Projet Python : Formulaire d'inscription

Ce projet montre comment créer une petite application graphique avec Tkinter et enregistrer des données dans une base SQLite.

1. Importation des bibliothèques

import tkinter as tk
from tkinter import messagebox
import sqlite3

tkinter permet de créer l'interface graphique.
messagebox permet d'afficher des fenêtres de dialogue.
sqlite3 permet de travailler avec une base de données SQLite.

2. Connexion à la base de données

connexion = sqlite3.connect("etudiants.db")
curseur = connexion.cursor()

Si le fichier etudiants.db n'existe pas, SQLite le crée automatiquement.

3. Création de la table

CREATE TABLE IF NOT EXISTS etudiant(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    prenom TEXT NOT NULL,
    email TEXT NOT NULL
)

La table contient :

  • id : identifiant automatique
  • nom : nom de l'étudiant
  • prenom : prénom
  • email : adresse email

4. Fonction enregistrer()

def enregistrer():

Cette fonction est exécutée lorsque l'utilisateur clique sur le bouton Enregistrer.

Lecture des champs

nom = entree_nom.get()
prenom = entree_prenom.get()
email = entree_email.get()

La méthode get() récupère le contenu des zones de texte.

Validation

if nom == "" or prenom == "" or email == "":

On vérifie qu'aucun champ n'est vide.

Insertion dans la base

curseur.execute("""
INSERT INTO etudiant(nom, prenom, email)
VALUES (?, ?, ?)
""", (nom, prenom, email))

Les caractères ? représentent des paramètres transmis à SQLite. Cette technique évite plusieurs problèmes de sécurité.

Sauvegarde

connexion.commit()

Les modifications sont enregistrées définitivement dans la base.

Vidage des champs

entree_nom.delete(0, tk.END)
entree_prenom.delete(0, tk.END)
entree_email.delete(0, tk.END)

Après l'enregistrement, les zones de texte sont effacées afin de permettre une nouvelle saisie.

5. Création de la fenêtre

fenetre = tk.Tk()

Cette instruction crée la fenêtre principale de l'application.

6. Création des composants graphiques

tk.Label(...)
tk.Entry(...)
tk.Button(...)
  • Label : affiche un texte.
  • Entry : permet la saisie.
  • Button : déclenche une action.

7. Bouton Enregistrer

command=enregistrer

Le clic sur le bouton exécute la fonction enregistrer().

8. Bouton Fermer

command=fenetre.destroy

Le clic sur ce bouton ferme l'application.

9. Boucle principale

fenetre.mainloop()

Cette boucle attend les actions de l'utilisateur (clavier, souris, clics sur les boutons, etc.).

10. Ce que l'étudiant apprend

  • Créer une interface graphique avec Tkinter
  • Créer une base SQLite
  • Créer une table
  • Insérer des données
  • Créer des fonctions Python
  • Valider un formulaire
  • Manipuler les boutons et événements
  • Vider les champs après traitement
