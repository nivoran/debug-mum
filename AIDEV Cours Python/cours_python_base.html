I- Introduction

Python est un langage de programmation moderne, interprété et très populaire, conçu pour être à la fois simple à lire et puissant à utiliser. Il est aujourd’hui l’un des langages les plus utilisés dans le monde, aussi bien dans l’éducation que dans l’industrie technologique.

×

🧠 Langage compilé vs interprété

Un langage compilé transforme tout le programme en fichier exécutable avant exécution. Un langage interprété exécute le code ligne par ligne grâce à un interpréteur.

⚙️ Langage compilé

C → Compilation → Exécutable

Exemples : C, C++, Rust

🐍 Langage interprété

Python → Interpréteur → Exécution

Exemples : Python, JavaScript

Créé par Guido van Rossum, Python a été pensé avec une philosophie claire : rendre le code facile à comprendre, même pour les débutants, tout en restant suffisamment robuste pour des projets professionnels complexes.

Python est utilisé dans de nombreux domaines : développement web (avec Flask ou Django), intelligence artificielle, data science, automatisation de tâches, cybersécurité, et même dans le développement de jeux vidéo.

L’un de ses plus grands avantages est sa syntaxe très lisible. Contrairement à d’autres langages, Python utilise l'indentation pour structurer le code, ce qui le rend plus propre et plus intuitif.

×

🧱 L'Indentation : C vs Python

En C, les blocs de code sont délimités par des accolades {}. En Python, c'est l'alignement (l'espace) qui définit le bloc.

Langage C

(Utilise des accolades)

if (age >= 18) {
    printf("Majeur");
    printf("Bienvenue");
}

Langage Python

(Utilise l'espace)

if age >= 18:
    print("Majeur")
    print("Bienvenue")

⚠️ En Python, si le décalage n'est pas identique pour toutes les lignes d'un même bloc, le programme s'arrête avec une IndentationError.

II.1. Installation

Avant de commencer à programmer en Python, vous devez installer l’interpréteur Python sur votre machine. Python est disponible gratuitement pour Windows, macOS et Linux.

Étapes d’installation (Windows)

  • Téléchargez Python depuis le site officiel : https://www.python.org
  • Lancez l’installeur téléchargé
  • Très important : cochez l’option "Add Python to PATH"
  • Cliquez sur Install Now

Vérification de l’installation

Ouvrez l’invite de commande (CMD) et tapez :


python --version

Si Python est correctement installé, vous verrez apparaître la version (ex: Python 3.x.x).

Utilisation de Python

Vous pouvez exécuter Python de deux façons :

  • Mode interactif : taper python dans le terminal
  • Fichier : créer un fichier .py et l’exécuter :
python mon_script.py

Éditeur recommandé

Un éditeur comme Visual Studio Code est fortement recommandé. Il offre :

  • Coloration syntaxique
  • Autocomplétion
  • Extensions Python

👉 Une bonne installation est essentielle pour éviter les erreurs dès le début.

II.2. Variables

En Python, une variable est un espace de stockage permettant de conserver une valeur (texte, nombre, booléen, etc.). Contrairement à certains langages, Python utilise un typage dynamique : vous n’avez pas besoin de déclarer le type à l’avance.

Déclaration de variables : Comparaison C vs Python

Langage C (Statique)

On doit préciser le type et finir par ;

char nom[] = "Jean";
int age = 25;
float taille = 1.75;
bool est_etudiant = true;

Python (Dynamique)

Le type est deviné par l'interpréteur.

nom = "Jean"
age = 25
taille = 1.75
est_etudiant = True

Note : Remarquez qu'en Python, les booléens prennent une majuscule (True) alors qu'en C, ils sont souvent en minuscules (true).

Types de données courants

  • str (chaîne de caractères) → "Bonjour"
  • int (entier) → 10
  • float (nombre décimal) → 3.14
  • bool (booléen) → True / False

Vérifier le type


print(type(nom))
print(type(age))

Concaténation et affichage

Python propose plusieurs façons d’afficher des variables :


# concaténation
print("Bonjour " + nom)

# f-string (recommandé)
print(f"Bonjour {nom}, tu as {age} ans")

Règles de nommage

  • Pas d’espaces (utiliser _)
  • Ne pas commencer par un chiffre
  • Utiliser des noms explicites (ex: age_utilisateur)

Conversion de type

On peut convertir une valeur d’un type à un autre :


age = "25"
age = int(age)

👉 Bien comprendre les variables est essentiel, car elles sont utilisées dans tous les programmes.

II.3. Structures de contrôle

Les structures de contrôle permettent de diriger le flux d’exécution d’un programme : prendre des décisions et répéter des actions.

Conditions (if / elif / else)


age = 20

if age >= 18:
    print("Majeur")
elif age == 17:
    print("Presque majeur")
else:
    print("Mineur")

👉 Le mot-clé elif permet d’ajouter des conditions intermédiaires.

Opérateurs de comparaison

  • > (supérieur à)
  • < (inférieur à)
  • == (égal à)
  • != (différent de)
  • >= (supérieur ou égal)
  • <= (inférieur ou égal)

Opérateurs logiques


age = 20
est_etudiant = True

if age >= 18 and est_etudiant:
    print("Étudiant majeur")
  • and : toutes les conditions doivent être vraies
  • or : au moins une condition vraie
  • not : inverse une condition

Boucle for

La boucle for est utilisée pour parcourir une séquence (liste, dictionnaire, etc.). 


for i in range(5):
    print(i)

Boucle while

La boucle while s’exécute tant qu’une condition est vraie. 


i = 0

while i < 5:
    print(i)
    i += 1

break et continue

Ces instructions permettent de contrôler les boucles. 


for i in range(10):
    if i == 5:
        break   # stop la boucle
    if i % 2 == 0:
        continue  # saute à l’itération suivante
    print(i)

Compréhension des structures

Contrairement à d’autres langages, Python utilise l’indentation pour définir les blocs de code. Une mauvaise indentation provoque une erreur.

👉 Bien maîtriser les structures de contrôle est essentiel pour écrire des programmes logiques et efficaces.

II.4. Tableaux (Listes et dictionnaires)

En Python, les structures de données les plus utilisées pour stocker plusieurs valeurs sont les listes et les dictionnaires.

Les listes

Une liste permet de stocker une collection ordonnée d’éléments. 


fruits = ["pomme", "banane", "orange"]

Accéder aux éléments


print(fruits[0])  # pomme
print(fruits[-1]) # dernier élément

Modifier une liste


fruits.append("mangue")
fruits.remove("banane")

Parcourir une liste


for fruit in fruits:
    print(fruit)

Les dictionnaires

Un dictionnaire stocke des données sous forme de clé/valeur. 


user = {
  "nom": "Jean",
  "age": 25
}

Accéder aux valeurs


print(user["nom"])

Modifier un dictionnaire


user["age"] = 26
user["ville"] = "Antananarivo"

Parcourir un dictionnaire


for cle, valeur in user.items():
    print(cle, valeur)

Structures imbriquées

On peut combiner listes et dictionnaires. 


etudiants = [
  {"nom": "Alice", "age": 20},
  {"nom": "Bob", "age": 22}
]

for e in etudiants:
    print(e["nom"])

👉 Les tableaux sont essentiels pour manipuler des collections de données dans tous les programmes.

II.5. Fonctions

Les fonctions permettent de regrouper du code dans un bloc réutilisable. Elles sont essentielles pour structurer un programme et éviter les répétitions.

Définir une fonction


def dire_bonjour(nom):
    return "Bonjour " + nom

Appeler une fonction

print(dire_bonjour("Alice"))

Paramètres multiples


def addition(a, b):
    return a + b

print(addition(2, 3))

Valeurs par défaut


def saluer(nom="Utilisateur"):
    return f"Bonjour {nom}"

print(saluer())

Retour de plusieurs valeurs


def calcul(a, b):
    return a + b, a - b

somme, difference = calcul(5, 2)

Portée des variables

Une variable définie dans une fonction est locale. 


def test():
    x = 10

# print(x)  ❌ erreur

Fonctions lambda

Les fonctions lambda sont des fonctions anonymes courtes. 


double = lambda x: x * 2
print(double(4))

Bonnes pratiques

  • Donner des noms explicites
  • Éviter les fonctions trop longues
  • Réutiliser les fonctions

👉 Les fonctions sont la base de tout programme structuré et évolutif.

III. Interfaces graphiques avec Tkinter

Tkinter est une bibliothèque intégrée à Python qui permet de créer des interfaces graphiques (GUI). Grâce à Tkinter, vous pouvez créer des fenêtres, des boutons, des champs de texte et rendre vos programmes interactifs.

Contrairement aux programmes en console, une interface graphique permet à l’utilisateur de cliquer, saisir des informations et interagir facilement avec votre application.

1. Créer une fenêtre


import tkinter as tk

fenetre = tk.Tk()
fenetre.title("Mon application")
fenetre.geometry("300x200")

fenetre.mainloop()

👉 Tk() crée la fenêtre principale
👉 mainloop() lance l’application

2. Ajouter du texte


label = tk.Label(fenetre, text="Bonjour Tkinter")
label.pack()

3. Ajouter un bouton


def cliquer():
    print("Bouton cliqué")

bouton = tk.Button(fenetre, text="Clique-moi", command=cliquer)
bouton.pack()

4. Champ de saisie


entree = tk.Entry(fenetre)
entree.pack()

def afficher():
    print(entree.get())

btn = tk.Button(fenetre, text="Afficher", command=afficher)
btn.pack()

5. Exemple complet


import tkinter as tk

def saluer():
    nom = entree.get()
    label_resultat.config(text="Bonjour " + nom)

fenetre = tk.Tk()
fenetre.title("Application Tkinter")

entree = tk.Entry(fenetre)
entree.pack()

bouton = tk.Button(fenetre, text="Valider", command=saluer)
bouton.pack()

label_resultat = tk.Label(fenetre, text="")
label_resultat.pack()

fenetre.mainloop()

Objectif pédagogique

  • Créer une interface graphique simple
  • Comprendre les widgets (Label, Button, Entry)
  • Gérer les événements (clic bouton)
  • Créer une interaction utilisateur
