📚 Corrigé Annoté – Examen SQL (Bibliothèque)

🟢 Niveau 1

1. Afficher tous les adhérents 
SELECT * FROM Adherent;
- SELECT * : sélectionne toutes les colonnes
- FROM Adherent : indique la table utilisée
👉 Requête de base pour afficher toute une table
2. Adhérents de Antananarivo 
SELECT * FROM Adherent
WHERE ville = 'Antananarivo';
- WHERE : permet de filtrer les résultats
- ville = 'Antananarivo' : condition de sélection
👉 On récupère uniquement les adhérents de cette ville
3. Trier les livres 
SELECT * FROM Livre
ORDER BY titre ASC;
- ORDER BY : trie les résultats
- ASC : ordre croissant (A → Z)
👉 Important : DESC = ordre inverse
4. Livres Informatique 
SELECT L.titre
FROM Livre L
JOIN Categorie C ON L.id_categorie = C.id_categorie
WHERE C.nom_categorie = 'Informatique';
- L et C : alias pour simplifier
- JOIN : relie les tables Livre et Categorie
- ON : condition de jointure
- WHERE : filtre la catégorie
👉 On combine 2 tables pour obtenir l'information

🟡 Niveau 2

5. Emprunts + noms 
SELECT E.id_emprunt, A.nom
FROM Emprunt E
JOIN Adherent A ON E.id_adherent = A.id_adherent;
- Jointure entre Emprunt et Adherent
- Permet d'associer chaque emprunt à un nom
👉 Cas classique relation clé étrangère
6. Livres empruntés 
SELECT L.titre, D.quantite
FROM Detail_Emprunt D
JOIN Livre L ON D.id_livre = L.id_livre;
- D = table de liaison
- On récupère le titre via jointure
👉 Montre l'utilisation des tables intermédiaires
7. Adhérents ayant emprunté 
SELECT DISTINCT A.nom
FROM Adherent A
JOIN Emprunt E ON A.id_adherent = E.id_adherent;
- DISTINCT : évite les doublons
👉 Important quand un adhérent a plusieurs emprunts

🔴 Niveau 3

8. Total livres par emprunt 
SELECT E.id_emprunt, SUM(D.quantite) AS total
FROM Emprunt E
JOIN Detail_Emprunt D ON E.id_emprunt = D.id_emprunt
GROUP BY E.id_emprunt;
- SUM() : fonction d’agrégation
- GROUP BY : regroupe par emprunt
👉 Indispensable pour les calculs
9. Emprunts > 1 livre 
SELECT E.id_emprunt, SUM(D.quantite) AS total
FROM Emprunt E
JOIN Detail_Emprunt D ON E.id_emprunt = D.id_emprunt
GROUP BY E.id_emprunt
HAVING SUM(D.quantite) > 1;
- HAVING : filtre après GROUP BY
👉 Différence clé : WHERE (avant), HAVING (après)
10. Plus gros emprunteur 
SELECT A.nom, SUM(D.quantite) AS total
FROM Adherent A
JOIN Emprunt E ON A.id_adherent = E.id_adherent
JOIN Detail_Emprunt D ON E.id_emprunt = D.id_emprunt
GROUP BY A.nom
ORDER BY total DESC
LIMIT 1;
- ORDER BY DESC : du plus grand au plus petit
- LIMIT 1 : prend le premier résultat
👉 Technique pour trouver un maximum
11. Nombre de livres par catégorie 
SELECT C.nom_categorie, COUNT(L.id_livre) AS nb
FROM Categorie C
JOIN Livre L ON C.id_categorie = L.id_categorie
GROUP BY C.nom_categorie;
- COUNT() : compte les éléments
👉 Très utilisé pour statistiques
12. Adhérents sans emprunt 
SELECT A.nom
FROM Adherent A
LEFT JOIN Emprunt E ON A.id_adherent = E.id_adherent
WHERE E.id_emprunt IS NULL;
- LEFT JOIN : garde tous les adhérents
- IS NULL : ceux sans correspondance
👉 Technique classique pour trouver “absence de données”
