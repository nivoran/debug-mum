🛒 Corrigé Annoté – Examen SQL (E-commerce)

🟢 Niveau 1

1. Afficher tous les clients 
SELECT * FROM Client;
- SELECT * : récupère toutes les colonnes
- FROM Client : table utilisée
👉 Requête de base
2. Clients de Antananarivo 
SELECT * FROM Client
WHERE ville = 'Antananarivo';
- WHERE : filtre les lignes
👉 On sélectionne une ville spécifique
3. Trier les produits par prix décroissant 
SELECT * FROM Produit
ORDER BY prix DESC;
- ORDER BY : tri
- DESC : du plus grand au plus petit
👉 Important pour les classements
4. Produits Informatique 
SELECT P.nom_produit
FROM Produit P
JOIN Categorie C ON P.id_categorie = C.id_categorie
WHERE C.nom_categorie = 'Informatique';
- JOIN : relie Produit et Categorie
- ON : condition de jointure
👉 On récupère les produits d’une catégorie

🟡 Niveau 2

5. Commandes avec clients 
SELECT C.id_commande, Cl.nom
FROM Commande C
JOIN Client Cl ON C.id_client = Cl.id_client;
- Association commande ↔ client
👉 Lecture d’une relation clé étrangère
6. Produits commandés avec quantité 
SELECT P.nom_produit, L.quantite
FROM Ligne_Commande L
JOIN Produit P ON L.id_produit = P.id_produit;
- Table intermédiaire Ligne_Commande
👉 Cas classique e-commerce
7. Clients ayant commandé 
SELECT DISTINCT Cl.nom
FROM Client Cl
JOIN Commande C ON Cl.id_client = C.id_client;
- DISTINCT : supprime les doublons
👉 Important si plusieurs commandes

🔴 Niveau 3

8. Total de chaque commande 
SELECT C.id_commande,
       SUM(P.prix * L.quantite) AS total
FROM Commande C
JOIN Ligne_Commande L ON C.id_commande = L.id_commande
JOIN Produit P ON L.id_produit = P.id_produit
GROUP BY C.id_commande;
- P.prix * L.quantite : calcul du montant
- SUM() : addition
- GROUP BY : par commande
👉 Requête très importante en pratique
9. Commandes > 500 
SELECT C.id_commande,
       SUM(P.prix * L.quantite) AS total
FROM Commande C
JOIN Ligne_Commande L ON C.id_commande = L.id_commande
JOIN Produit P ON L.id_produit = P.id_produit
GROUP BY C.id_commande
HAVING SUM(P.prix * L.quantite) > 500;
- HAVING : filtre après agrégation
👉 Différence clé avec WHERE
10. Client ayant le plus dépensé 
SELECT Cl.nom,
       SUM(P.prix * L.quantite) AS total
FROM Client Cl
JOIN Commande C ON Cl.id_client = C.id_client
JOIN Ligne_Commande L ON C.id_commande = L.id_commande
JOIN Produit P ON L.id_produit = P.id_produit
GROUP BY Cl.nom
ORDER BY total DESC
LIMIT 1;
- SUM : total dépensé
- ORDER BY DESC : classement
- LIMIT 1 : premier
👉 Technique pour trouver le maximum
11. Nombre de produits par catégorie 
SELECT C.nom_categorie,
       COUNT(P.id_produit) AS nb
FROM Categorie C
JOIN Produit P ON C.id_categorie = P.id_categorie
GROUP BY C.nom_categorie;
- COUNT : nombre d’éléments
👉 Utilisé pour statistiques
12. Clients sans commande 
SELECT Cl.nom
FROM Client Cl
LEFT JOIN Commande C ON Cl.id_client = C.id_client
WHERE C.id_commande IS NULL;
- LEFT JOIN : garde tous les clients
- IS NULL : pas de correspondance
👉 Permet de détecter les clients inactifs
