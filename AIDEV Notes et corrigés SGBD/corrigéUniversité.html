🎓 Corrigé Annoté – Examen SQL (Université)

🟢 Niveau 1

1. Afficher tous les étudiants 
SELECT * FROM Etudiant;
- SELECT * : récupère toutes les colonnes
- FROM Etudiant : table utilisée
👉 Requête de base
2. Étudiants de Antananarivo 
SELECT * FROM Etudiant
WHERE ville = 'Antananarivo';
- WHERE : filtre les lignes
👉 Sélection d’une condition précise
3. Trier les étudiants par nom 
SELECT * FROM Etudiant
ORDER BY nom ASC;
- ORDER BY : tri des résultats
- ASC : ordre alphabétique
👉 DESC permettrait l’inverse
4. Cours de la formation Informatique 
SELECT C.nom_cours
FROM Cours C
JOIN Formation F ON C.id_formation = F.id_formation
WHERE F.nom_formation = 'Informatique';
- JOIN : relie les tables
- ON : condition de jointure
👉 Permet de naviguer entre tables liées

🟡 Niveau 2

5. Étudiants avec leur formation 
SELECT E.nom, F.nom_formation
FROM Etudiant E
JOIN Inscription I ON E.id_etudiant = I.id_etudiant
JOIN Formation F ON I.id_formation = F.id_formation;
- Double JOIN : relie 3 tables
👉 Très fréquent en base relationnelle
6. Notes avec étudiants et cours 
SELECT E.nom, C.nom_cours, N.note
FROM Note N
JOIN Etudiant E ON N.id_etudiant = E.id_etudiant
JOIN Cours C ON N.id_cours = C.id_cours;
- Association note ↔ étudiant ↔ cours
👉 Lecture complète d’une relation
7. Étudiants en Informatique 
SELECT E.nom
FROM Etudiant E
JOIN Inscription I ON E.id_etudiant = I.id_etudiant
JOIN Formation F ON I.id_formation = F.id_formation
WHERE F.nom_formation = 'Informatique';
- Filtrage après jointure
👉 Important pour requêtes ciblées

🔴 Niveau 3

8. Moyenne par étudiant 
SELECT E.nom, AVG(N.note) AS moyenne
FROM Etudiant E
JOIN Note N ON E.id_etudiant = N.id_etudiant
GROUP BY E.nom;
- AVG() : moyenne
- GROUP BY : regroupe par étudiant
👉 Indispensable pour calculs statistiques
9. Étudiants avec moyenne > 12 
SELECT E.nom, AVG(N.note) AS moyenne
FROM Etudiant E
JOIN Note N ON E.id_etudiant = N.id_etudiant
GROUP BY E.nom
HAVING AVG(N.note) > 12;
- HAVING : filtre sur agrégation
👉 Différence avec WHERE
10. Meilleure moyenne 
SELECT E.nom, AVG(N.note) AS moyenne
FROM Etudiant E
JOIN Note N ON E.id_etudiant = N.id_etudiant
GROUP BY E.nom
ORDER BY moyenne DESC
LIMIT 1;
- ORDER BY DESC : classement
- LIMIT 1 : premier résultat
👉 Technique pour trouver un maximum
11. Nombre d’étudiants par cours 
SELECT C.nom_cours, COUNT(N.id_etudiant) AS nb
FROM Cours C
JOIN Note N ON C.id_cours = N.id_cours
GROUP BY C.nom_cours;
- COUNT() : comptage
👉 Très utilisé en analyse de données
12. Étudiants sans note 
SELECT E.nom
FROM Etudiant E
LEFT JOIN Note N ON E.id_etudiant = N.id_etudiant
WHERE N.id_note IS NULL;
- LEFT JOIN : garde tous les étudiants
- IS NULL : absence de correspondance
👉 Permet de détecter les cas “vides”
